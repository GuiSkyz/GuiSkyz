## `> whoami`

Sou desenvolvedor **Full Stack**, com uma preferência bem clara por **backend, arquitetura, integrações, automação e inteligência artificial**.

Gosto de transformar problemas reais em sistemas organizados, pensando não apenas no código, mas também em:

- arquitetura;
- dados;
- regras de negócio;
- integrações;
- infraestrutura;
- segurança;
- experiência de quem vai utilizar;
- e como tudo isso pode evoluir depois.

Meu objetivo não é simplesmente fazer uma funcionalidade funcionar.

Quero entender **por que ela existe, onde ela deveria estar e como ela se conecta ao restante do sistema**.

## `05. Alguns princípios`

```yaml
engineering:
  understand_before_building: true

  priorities:
    - clareza
    - manutenibilidade
    - segurança
    - boa experiência
    - arquitetura que faça sentido

  avoid:
    - complexidade sem necessidade
    - tecnologia escolhida por hype
    - abstrações sem propósito
    - "funciona, então está pronto"

  objective:
    "Construir sistemas simples de usar,
     mesmo quando existe bastante complexidade por trás."
```
